# Historical web demonstrator

This directory contains the complete pre-native Threshiator web application. It is retained as behavioral and algorithmic evidence; it is not part of the native application's runtime.

The pre-conversion working-tree edits in `src/main.ts` and `styles/main.css` were preserved byte-for-byte during the move.

```sh
cd archive/webapp
npm install
npm run dev
```

Checks remain available with `npm test`, `npm run typecheck`, and `npm run build`. The original project documentation is in `LEGACY_README.md`.
