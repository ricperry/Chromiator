# GTK warning cleanup and bounded bug hunt

## Implemented

- Replaced deprecated GtkDialog use in `src/native_dialog.rs` with a modal
  GtkWindow, stable named responses, destructive-button styling, and
  single-assignment asynchronous completion. Dropping a waiting future destroys
  its modal window; close/destroy resolve as cancellation.
- Removed the unused GTK prelude import from `src/components.rs` and the unused
  narrow breakpoint constant from `src/main.rs`. No new automatic responsive
  behavior was introduced.
- Extracted the drag-completion helper in `src/site_editor.rs` to keep state
  access under one borrow, before GTK refresh. Added a regression exercising
  separate drag undo steps, redo, no-motion completion, and locked sites.
- Added two dialog-completion regressions for cancellation, response identity,
  and waking the waiting future only once.
